Armarist Clone – v1.0 (Static & Responsive Base)

Ricostruzione del layout del sito Armarist.
Questa prima versione del progetto si concentra sulla fedeltà visiva, sulla struttura semantica e sull’implementazione della responsività di base tramite CSS puro, in linea con le richieste dell’esercitazione.

🚀 Obiettivi Raggiunti (v1)

Struttura semantica: organizzazione dei contenuti secondo una struttura chiara e coerente.

Layout responsive: approccio mobile-first basato su Flexbox.

Media queries: implementazione di un singolo breakpoint (576px) come richiesto dal brief, applicato a tutte le sezioni della homepage.

Navigazione mobile: presenza dell’hamburger menu non interattivo, come da specifiche dell’esercizio.

⚠️ Nota: l’esercitazione prevedeva la realizzazione della sola homepage, senza interattività JavaScript o componenti avanzati.

🛠️ Stack Tecnologico

HTML5

CSS3

📋 Roadmap & Sviluppi Futuri (v2)

Possibili miglioramenti e implementazioni future, non necessariamente in ordine di priorità:

 Miglioramento dell’accessibilità (supporto screen reader, focus states, aria attributes).

 Implementazione dell’hamburger menu funzionante.

 Responsività avanzata su ulteriori breakpoint (tablet e desktop).

 Interactive counters in JavaScript (attivazione on scroll).

 Animazioni CSS per la comparsa dei contenuti (scroll-based).

 Inserimento di UI components (es. accordion).

 Attivazione e validazione di tutti i link di navigazione.
